# vimember Current Status

> 本文件记录当前实现状态、已知问题和待确认事项。开始修具体功能前按需查阅，实际分支以 `git status` 为准。

## 1. 当前实现状态

1. 首页顶部专辑栏已改为 `70pt` 圆角方形卡片，添加专辑卡片和 morph 动画已按该形状调整；添加专辑卡片整体位置和圆角已微调。
2. 首页右下添加按钮已移动到右下角，`58pt` 基准尺寸、`28pt` 基准边距；搜索入口已隐藏。
3. 首页右上显示模式切换和右下添加按钮在 iOS 26 及以上已采用原生 Liquid Glass，其他共享 Liquid Glass 按钮也已统一为同一实现方向；iOS 17-25 走同尺寸 material fallback。
4. 详情页底部文字面板已从状态切换式 sheet 重构为 `panelProgress` 驱动的 persistent 毛玻璃面板；文字保持白色，展开时背景增强清晰度。
5. 详情页视频已支持随文字上滑产生 1/3 比例视差上移和渐进模糊；横屏上下融合层与视频移动同步，blur 在 mask 前，避免边缘消失。
6. 详情页顶部右侧按钮已从删除圆按钮 morph 到编辑跑道圆；行为按 `panelProgress` 切换。
7. 详情页横线已改成视频进度条；文字展开后视频暂停，收回后继续播放，拖动进度条可 seek。
8. 添加文字页正文输入的 UIKit `UITextViewRepresentable` 焦点桥接已修复，输入第一个字符后键盘不应自动收起。
9. 详情页视频已启用声音；首页/列表/preview 视频仍应保持静音。
10. 首页视频卡片已加入系统 Context Menu：单栏和三列卡片长按出现 Delete / Share / Edit。

## 2. 已知问题

1. 首页长按 Context Menu 的浮起 preview 中，竖版视频仍存在上下裁切/显示不完整问题。
2. 该 preview 问题不要通过自绘菜单、截图 preview、zIndex 或 LongPressGesture 修补；后续应继续围绕系统 previewProvider、source view 尺寸和视频比例链路排查。
3. 正式专辑持久化数据模型、完整专辑详情页仍待确认。

## 3. 待确认问题

1. 摘要固定字数、行数和截断样式。
2. 首页“最主要的一条视频”的视觉和算法判定方式。
3. 画廊专辑创建流程、专辑命名方式和专辑数据模型。
4. 点击某个专辑后的专辑详情页布局、标题位置和返回方式。
5. 首页、画廊、导入和编辑页面后续新增状态的具体 Figma 节点。
6. 首页和预览视频默认静音；详情页视频当前需要有声音。是否增加显式播放/静音控制条后续确认。
7. 是否需要浅色和深色模式。
8. 首页日期显示方式切换的具体规则。
9. 搜索入口当前隐藏；是否恢复搜索、搜索范围、搜索结果页和空状态后续确认。
