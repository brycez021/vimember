# vimember Figma and UI Rules

> 本文件承接原 `AGENTS.md` 中的 Figma、首页尺寸换算和视频融合规则。做视觉或交互精修时读这里。

## 1. Figma 来源

正式 UI 来源：

https://www.figma.com/design/z9ewZ9itwDRhTMK94G08u1/vimember?node-id=0-1&t=xXw4CqlJl4XHgkaf-1

正式制作 UI 时必须遵守：

1. 必须按用户当次指令读取用户指定的 Figma 页面、Frame、组件或节点。
2. 不得在未读取指定 Figma 内容前凭想象实现界面。
3. 不得把文档文字描述替代 Figma 视觉细节。
4. 颜色、字体、间距、圆角、阴影、图标、布局比例、状态样式和文案层级都应尽量贴近 Figma。
5. 如果 Figma 中存在不清楚、缺失或互相冲突的内容，必须先询问用户。

## 2. 首页屏幕尺寸换算规则

首页 `首页` Frame 中的手机屏幕范围以 Figma 的 `iPhone Air` 图层为参考，尺寸为 `420pt * 912pt`。实现首页悬浮按钮、屏幕边距和与屏幕边缘有关的位置时，必须遵守：

1. 所有屏幕相关尺寸和位置按真实设备屏幕尺寸计算，单位使用 iOS point，不使用像素。
2. 真实屏幕尺寸优先取 `UIScreen.main.bounds.size` 作为换算依据。
3. 以 Figma `iPhone Air` 的 `420pt * 912pt` 为参考尺寸：横向尺寸和左右边距按 `screenWidth / 420` 缩放，纵向位置和上下边距按 `screenHeight / 912` 缩放。
4. 不得只用 SwiftUI 容器高度、滚动内容高度或安全区 inset 代替真实屏幕高度来计算首页悬浮按钮位置。
5. 当前首页悬浮控件已确认的基准值为：右上显示模式切换 `100pt * 44pt`，距右 `20pt`、距上 `52pt`；右下添加按钮 `58pt * 58pt`，距右 `28pt`、距底 `28pt`。搜索入口当前隐藏，即使代码保留也不得显示。
6. 首页右上切换和右下加号在 iOS 26 及以上均使用原生 Liquid Glass；如果再次尝试 `.buttonStyle(.glass)` 导致尺寸不可控，应退回 `.glassEffect(.regular.interactive(), in:)`。iOS 17-25 只使用同尺寸 material fallback。

## 3. 首页视频底色与渐进融合规则

已从 Figma `首页` Frame 读取并与用户确认的规则：

1. 首页 `首页` Frame 节点为 `13:877`。
2. 竖屏示例 `image 59` 尺寸为 `420pt * 745pt`，竖屏纯色底与视频同高，不得超出视频高度。
3. 竖屏文字标题顶部位于视频底部上方约 `114pt`；实现时文字不能与视频清晰内容硬碰，文字背后需要有从下到上逐渐减弱的模糊融合。
4. 横屏示例中纯色底节点 `Rectangle 1032` 为 `420pt * 322pt`，横屏视频节点 `image 58` 为 `420pt * 236pt`，纯色底向下超出视频 `86pt`。
5. 横屏文字标题顶部位于视频底部上方约 `28pt`。
6. Figma 横屏图片层使用 `PROGRESSIVE` layer blur，最大半径为 `100`，模糊从视频下半段开始向下逐渐增强；当前 SwiftUI 原型不新增横屏封面/视频模糊层，而是用清晰视频渐隐 mask 和动态取色透明渐变罩近似“边缘化开”的效果。
7. 横屏实现必须让视频在到达真实下边界前已经自然化开，再由下方纯色底接住，避免视频真实底边或色块顶部出现明显横向分界线。
8. 竖屏实现使用更大范围的取色渐变罩和轻微视频底部渐隐来加强文字背后的融合；竖屏纯色底仍与视频同高。
9. 当前首页文字层必须绘制在视频融合层之上；纯色渐变罩不得盖在文字上方。
10. 当前首页竖屏文字已按用户截图微调，横屏卡片文字逻辑已按用户要求复制竖屏当前逻辑：标题、日期、横线、正文的 top-from-bottom 基准分别为 `125pt`、`91.5pt`、`66pt`、`60.5pt`，整体偏移为 `0`，左边距为 `23pt`。
11. 首页最上方和最下方叠加轻量白色渐变模糊层，用于柔和屏幕边缘；该层应保持淡白透明，主要依赖渐变模糊，不得明显遮挡内容。

## 4. 画廊视觉规则入口

详细画廊产品行为在 [PRODUCT_REQUIREMENTS.md](PRODUCT_REQUIREMENTS.md)。做画廊视觉时重点确认：

1. 画廊视图视觉来源为 Figma `Frame 8`，节点 `158:550`。
2. 顶部有 `Albums` 专辑栏，下方有 `All Videos` 视频网格。
3. 专辑封面当前为 `70pt` 基准的圆角方形卡片，外圆角 `10pt`，缩略图为轻微 inset 的圆角矩形。
4. 视频区域按 Figma 三列卡片排列；卡片左右缝隙和上下缝隙必须一致。
5. 视频卡片圆角为 `3pt`；贴近屏幕边缘的外侧角保持直角。

## 5. Liquid Glass 控件规则

1. iOS 26 及以上的可点击 Liquid Glass 按钮统一使用 `Button` + 固定尺寸内容 + `.glassEffect(.regular.interactive(), in:)` + `.buttonStyle(.plain)`；iOS 17-25 使用同尺寸兼容 material fallback。
2. 不要恢复旧的自定义半透明白底、stroke、shadow、高光来手搓按钮玻璃。
3. 首页右上显示模式切换和右下添加按钮必须保持已确认尺寸和真实屏幕换算规则。
