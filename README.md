# vimember

vimember 是一个计划中的 iOS 视频日记 App。核心体验是：从系统相册导入视频，为视频添加文字，然后在首页列表、画廊和详情页中回看这些视频日记。

当前仓库阶段：已完成指导文件整理、iOS 工程脚手架、首页原型、添加视频流程原型、详情页原型和画廊页原型。首页视频卡片、动态取色、横竖屏底色与渐进透明融合、详情页文字层、添加/编辑流程和画廊网格正在按 Figma 与用户截图校准。

## 产品目标

vimember 要解决的是一种轻量的视频记忆记录需求：

1. 从相册选择或导入视频。
2. 导入后进入编辑页。
3. 给视频写一段文字。
4. 完成编辑，保存为视频日记。
5. App 使用复制到本地沙盒的视频文件进行展示和播放。
6. 在首页以纵向列表查看所有视频日记。
7. 在画廊视图查看所有视频日记。
8. 点进详情页查看完整视频和完整文字。

## 核心视图

### 首页视图

- 所有视频日记上下排列。
- 视频按时间倒序排列，最新视频在最上面；打开首页时最上面视频卡片上边界与屏幕上边界对齐。
- 视频和搭配的文字必须放在一起展示。
- 首页只展示文字摘要。
- 点击可以进入详情视图。
- 上下滑动时视频不动；停止滑动后，只播放当前屏幕中最主要的一条可见视频。
- Figma 中 `首页` Frame 是首页正式 UI 来源，Frame 内包含上下超出屏幕的内容和屏幕范围标识。
- 首页必须适配不同尺寸 iPhone。
- 首页视频效果参考 `/Users/zhangsiyuan/Documents/视频` 中的“文稿/视频”demo，但只参考效果，不参考实现方式，最终以 Figma 画出来的感觉为准。
- 每个视频有动态取色的纯色底；竖屏纯色底与视频同高，横屏纯色底高于视频并向下超出。
- 视频底部用动态取色渐变罩和清晰视频渐隐与纯色底融合，不能出现清晰视频、融合层或纯色底之间的明显分界线；当前横屏不新增模糊封面层，而是让视频边缘在真实下边界前化开并融入同色背景。
- 首页文字区域包含标题、日期、横线和正文，正文超过两行时只显示两行。
- 左下角跑道圆是搜索框入口，右下角圆形按钮是添加新内容，右上角圆形按钮打开切换设置。
- 右上角按钮当前与详情页圆形按钮保持同样尺寸、上边距和右边距。
- 切换设置卡片以 Figma `首页-切换` Frame 为准，包含日期显示方式切换和切换到画廊视图；日期切换规则后续确认。
- 首页最上方和最下方有淡白色渐变模糊层，用于柔和屏幕边缘。

### 添加视频流程

- 首页右下角加号进入视频选择页，视觉来源为 Figma `选择视频` Frame。
- 视频选择页中所有视频按正方形裁剪展示。
- 选中视频后显示高亮标记和小对号，点击右上角对号先进入视频预览页。
- 视频预览页视觉来源为 Figma `添加-视频页` Frame，只展示选中的一条视频，自动播放。
- 添加视频页不管横屏还是竖屏，视频都居中显示，并在视频上边缘和下边缘丝滑融入动态取色背景。
- 视频预览页底部向下箭头进入添加文字页。
- 添加文字页视觉来源为 Figma `添加-文字页` Frame，背景颜色与视频预览页下方纯色底一致，左上角返回选择视频，右上角确定完成流程回首页。
- 添加文字页上方箭头滚回视频预览页，正文不设固定显示高度，超出屏幕后通过页面滚动查看。

### 画廊视图

- 展示已经加入的视频日记。
- 只展示文字摘要。
- 点击可以进入详情视图。
- 视觉来源为 Figma `Frame 8`，节点 `158:550`。
- 顶部为 `Albums` 专辑栏，专辑圆横向滚动；第一个圆是添加新专辑入口的视觉占位。
- 专辑栏下方有白到浅灰的渐变阴影背景。
- 视频区标题为 `All Videos`，下方为三列卡片网格，用户可以纵向滑动查看更多。
- 每个卡片保留视频中间正方形画面，下面垫动态取色纯色背景，视频底部丝滑融入背景。
- 卡片下方显示两行标题，过长省略；卡片缝隙横竖一致，圆角为 `3pt`，贴屏幕边缘的外侧角保持直角。
- 专辑创建流程、点击专辑后的专辑详情页暂不实现，等待后续确认。

### 详情视图

- 展示完整视频。
- 展示完整文字。
- 视频自动播放并循环播放。
- 左上角返回，右上圆形按钮删除，右上跑道圆按钮编辑。
- 删除会先弹确认，确认后只删除 App 本地记录和 App 沙盒视频文件，不删除系统相册原视频。
- 点击编辑进入添加文字/视频编辑态。
- 文字卡片可从视频底部滑上来占满全屏，并继续滚动查看全文；展开后的背景颜色沿用视频底部动态取色底色。
- 横屏详情视频在屏幕中视觉居中，上下边缘都融入动态取色背景。

## 已确认决策

1. 视频导入后复制到 App 本地沙盒。
2. 文字保存在 App 本地数据库。
3. 摘要显示正文前面固定字数的一部分，具体字数和样式后续确认。
4. 导入后必须进入编辑页，并且新建流程先显示添加-视频页。
5. 首页同一时间只播放最主要的一条视频。
6. 支持再次编辑。
7. 支持删除，但任何时候都不删除系统相册原视频。
8. 最低支持 iOS 17.0。
9. 后续可能在第二版加入视频分类功能，第一版不实现。
10. 项目使用 GitHub 做版本管理，默认 `main` 为稳定分支，开发分支使用 `codex/` 前缀。
